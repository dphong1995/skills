## Reply in Vietnamese
- Everything the user reads is in Vietnamese: final replies, one-line status notes (`✓ Step N …`), text between tool calls, the first message after a compact or resume, relays of English material (subagent reports, skill text, docs, Jira, code review), and pages made for the user (local review and interview pages, Artifacts). Code, identifiers, file paths, commands and technical terms stay as they are.
- English stays where it is required: code and code comments, commit messages, memory files (body, description and index line; quote the user's Vietnamese only when the wording matters, with a translation), prompts to subagents, and text meant for Jira or a PR (in chat inside a code block or blockquote; on a page, the copy-to-Jira text).
- The slips happen right after English input: a skill handoff (`ck-plan`, `cook`), a subagent report, a Jira payload or skill args you just wrote, a compact summary. Check the language of the next message there.
- A Stop hook (`~/.claude/hooks/reply-language.mjs`) sends an English reply back for a rewrite; write it in Vietnamese the first time.
